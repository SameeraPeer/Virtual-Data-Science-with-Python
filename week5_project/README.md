# Week 5: Capstone Project (Virtual Data Science with Python)

End-to-end analysis of the Breast Cancer Wisconsin (Diagnostic) dataset that
integrates Weeks 1-4 and ends with strategic recommendations.

- `week5_capstone.py`: full analysis (audit, EDA, hypothesis tests, models, cost-based cut-off, feature reduction)
- `Week5_Capstone_Report.docx`: the final report
- `figures/`: all figures used in the report
- `reports/`: `results.json`, `hypothesis_tests.csv`, `eda_summary.txt`

## Run
```
pip install -r requirements.txt
python week5_capstone.py
```
No internet needed: the dataset ships with scikit-learn. Seed 42 is used throughout.

Educational project on a public benchmark. Not a medical device.
